# BodyProfile Tracker V7.1 · 모바일 UI

## 오늘 요일 자동 선택

앱을 열 때 기기의 현지 날짜를 기준으로 프로그램을 선택합니다. 월·수 수영, 화 UPPER, 목 LOWER+CORE, 금 러닝, 토 결손 보충, 일 휴식입니다. 화면을 열어 둔 상태에서 날짜가 바뀌거나 다음 날 앱으로 돌아와도 오늘 일정으로 전환합니다.

선택 메뉴로 다른 운동을 직접 고를 수 있으며 ‘오늘 일정으로’를 누르면 원래 일정으로 돌아옵니다. 새로고침하면 오늘 요일을 다시 자동 선택합니다. 기존 운동 기록은 유지합니다.

## 모바일 화면 변경

- 운동 화면에서 바로 세트 기록을 시작할 수 있도록 습관과 주간 출석을 대시보드로 이동했습니다.
- 세트별 지난 기록 / 중량 / 횟수 / 완료를 같은 줄에서 확인합니다.
- 중량 ±1kg, 44px 완료 체크, 하단 운동 시작·종료 및 다음 세트 버튼을 제공합니다.
- 세트 완료 시 스크롤 위치를 유지합니다. 각 운동 카드는 접을 수 있습니다.
- 종목 변경·메모·전체 완료·드롭세트는 카드 안의 펼침 메뉴에서 이용합니다.
- 숫자를 입력하는 동안 하단 고정 조작부를 숨겨 키보드 공간을 확보합니다.
- 저장 데이터 구조와 운동 프로그램은 V7을 유지합니다. 파일을 덮어쓰면 됩니다.

참고한 공식 기능 안내: [Hevy 세트 기록과 자동 휴식](https://www.hevyapp.com/features/track-workouts/), [Hevy 지난 세트 비교](https://www.hevyapp.com/features/track-exercises/), [Strong 운동 기록](https://help.strongapp.io/article/229-my-first-workout). 로고나 화면 이미지를 복제하지 않고 기록 흐름을 참고했습니다.

V6 단일 HTML을 기반으로 제작했습니다. CSS·JavaScript·차트는 index.html 안에 포함되어 있으며 외부 라이브러리를 불러오지 않습니다.

## GitHub Pages 업데이트

1. 기존 앱에서 JSON 백업을 다운로드합니다.
2. ZIP을 풀고 안의 파일을 기존 GitHub 저장소의 index.html이 있는 위치에 덮어씁니다. ZIP 자체를 업로드하지 않습니다.
3. 기존 GitHub Pages 주소로 접속해 제목에 V7이 표시되는지 확인합니다. 반영이 늦으면 온라인 상태에서 다시 접속하고 새로고침합니다.
4. 다른 브라우저나 새 기기로 옮겼다면 앱의 백업 탭에서 기존 JSON을 복원합니다.

기존 주소와 브라우저를 유지하세요. 사이트 데이터/localStorage를 삭제하지 마세요. 단독 HTML을 로컬에서 여는 것은 기존 GitHub Pages와 다른 저장 공간이므로 기록이 자동 공유되지 않습니다.

## 포함 파일

- index.html: 전체 앱
- manifest.json, sw.js, icon.svg, icon-192.png, icon-512.png: 설치 및 오프라인 지원
- README.md, 검증결과.md: 사용 안내와 검증 범위

GitHub Pages에서 한 번 온라인으로 정상 로딩하여 서비스 워커 설치가 완료되면 오프라인 재접속할 수 있습니다. iPhone에서는 Safari 공유 메뉴의 ‘홈 화면에 추가’를 사용합니다. 유튜브 자세 검색은 온라인 연결이 필요합니다. 진동은 브라우저가 지원할 때만 동작합니다.

## 데이터 보존

저장 키는 `bp_v4_straight_set_2026`을 그대로 사용합니다. 기존 필드를 유지하고 V7 필드를 추가합니다. V4/V5/V6의 원본 객체, `data`로 감싼 백업, 저장 키로 감싼 백업을 복원할 수 있습니다. 복원은 현재 데이터 교체 방식이며 실행 전 확인 창을 표시하고 현재 데이터를 별도 키에 보관합니다.

최초 V7 마이그레이션 전 원본: `bp_v4_straight_set_2026_pre_v7`

바벨로우 이상치 원본: `bp_v4_straight_set_2026_v7_outlier_originals`. JSON 내 `migrationV7.originals`에도 포함됩니다. 바벨로우 weight ≥800은 80kg으로 보정하며, 관련 세션 최고 중량과 볼륨을 다시 계산합니다. 다른 종목 고중량은 변경하지 않습니다.

체성분 시드는 해당 날짜 기록이 없을 때만 추가합니다. 6월의 종목 완료 체크도 아카이브에 표시합니다. 원본에 세트별 중량·횟수가 없는 기록은 값을 추측하지 않습니다.

개인 백업 파일 자체는 배포 ZIP에 포함하지 않았습니다.

## V7 사용

- 화요일 8종목 26세트, 목요일 8종목 25세트. 목표 55~60분.
- 기준 중량은 첫 기록에만 표시하고 이후에는 해당 종목의 지난 수행 기록을 우선합니다. 기구별 중량을 섞지 않도록 대체 종목 기록은 별도로 보관합니다.
- 중량 ± 버튼은 1kg 단위입니다. 직접 입력은 소수 중량도 지원합니다. 지난 동일 세트 중량 대비 ±50%를 초과하면 확인 후 저장합니다.
- 모든 정규 세트가 완료되고 반복 상단에 도달하면 다음 세션에 증량을 제안합니다. 스쿼트·RDL·레그프레스 +5kg, 나머지 +2.5kg. 수락은 미완료 세트에 적용하고 거절하면 지난 중량을 유지합니다.
- 최근 3회 완료 세트의 중량·반복이 모두 같으면 정체를 표시합니다. 미완료 기록으로 정체를 판정하지 않습니다.
- 35→30→25kg 드롭세트는 마지막 정규 세트 뒤의 별도 체크입니다. 정규 세트 완주율에는 추가하지 않습니다.
- 토요일은 빠진 주중 세션만 보충합니다. 월/수 수영도 원래 날짜로 구분합니다. 보충 완료 체크를 해제하면 해당 세션이 자동 인정한 출석도 취소합니다.
- 완주율은 완료 세트/계획 세트입니다. 60분을 넘기면 남은 카프레이즈 생략 안내를 표시하며 생략한 세트를 완료로 처리하지 않습니다.
- 습관: 프리로드, 크레아틴, 점심 후 15분 걷기, 포징 연습. 뒤의 두 항목은 이름 변경이 가능합니다.
- 휴식 타이머는 실제 경과 시간으로 계산합니다. 휴대폰 화면이 잠기면 브라우저가 알림을 지연하거나 중단할 수 있습니다.
