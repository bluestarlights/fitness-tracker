모바일 세트는 중량·횟수를 나란히 표시하고 각 숫자 아래에 +/- 버튼을 배치합니다. 입력 숫자 20px, 중량 세 자리·횟수 두 자리 표시 공간 확보, +/- 44×44px. V7.3 JavaScript 동작과 데이터 구조를 유지합니다.
