# BodyProfile Tracker V8

머신 커팅 프로그램용 개인 트레이닝 로그. 단일 `index.html` PWA.

## 업로드할 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (CSS·JS 포함) |
| `sw.js` | 서비스워커 (오프라인 + 자동 업데이트) |
| `manifest.json` | 홈 화면 설치 정보 |
| `icon.svg` | 앱 아이콘 |
| `icon-maskable.svg` | 안드로이드 마스커블 아이콘 |

저장소에 남아 있는 `app.js` 와 `style.css` 는 `index.html` 이 전혀 불러오지 않는
예전 버전의 잔재이므로 깃허브에서 삭제해도 됩니다.

## 데이터

- 저장 키 `bp_v4_straight_set_2026` 을 V4~V7 그대로 사용합니다.
- 기존 필드는 삭제하지 않고 신규 필드만 추가합니다.
- V4/V5 의 `inputs` 값은 세트 단위 `setData` 로 자동 보완됩니다.
- 기록은 브라우저에만 있으므로 기기를 바꾸기 전에 반드시 JSON 백업을 받으세요.

## V7.1 에서 바뀐 것

### 고친 버그
- 날짜를 UTC 로 계산하던 문제. 새벽 0~9시 운동이 전날로 기록되던 것을 지역 시간 기준으로 수정.
- 지난 세션에서 미리 채워진 중량·횟수가 저장되지 않아 볼륨과 추이가 0 으로 남던 문제.
- 휴식 타이머가 화면을 끄면 어긋나던 문제. 이제 시각 기준으로 계산합니다.
- 서비스워커가 항상 캐시를 먼저 쓰는 바람에 새 버전을 올려도 반영되지 않던 문제.
  이제 HTML 은 네트워크 우선이라 다음 접속에서 바로 갱신됩니다.
- 차트 축 라벨이 잘리던 문제 (`120kg` 이 `20kg` 으로 보이던 현상).
- 테마와 맞지 않던 색 잔재 (하단 탭의 주황색, 빨간 그림자).

### 기능
- JSON 복원 전에 현재 기록과 파일 내용을 비교해 보여주는 확인창. 덮어쓰기 직전 상태를 한 번 자동 보관.
- 전체 삭제는 2단계 확인.
- 세션 종료 시 세트 수와 볼륨 요약.
- 체성분 추이를 체중·골격근·체지방 3개로 분리. 단위가 달라 한 축에 겹쳐 그리지 않습니다.
- 차트를 누르면 해당 날짜 값이 표시됩니다.
- 세트 체크 시 전체 목록을 다시 그리지 않고 해당 줄만 갱신합니다.

### 디자인
- 딥 네이비 + 시안 → 중립 근흑색 + 라임 액센트 한 가지.
- 글래스모피즘과 이모지 제거, 선 아이콘(Tabler, MIT)으로 교체.
- 모든 터치 대상 44px 이상.
- 운동 목록이 첫 화면에서 바로 보이도록 순서 재배치. 주간 스케줄은 목록 아래로 이동.
- 웹폰트를 9개 파일에서 Pretendard Variable 동적 서브셋 1개로 축소.
- `prefers-reduced-motion` 과 `prefers-reduced-transparency` 지원.
