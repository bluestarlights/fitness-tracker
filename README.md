# BodyProfile Tracker V8.2

머신 커팅 프로그램용 개인 트레이닝 로그. 단일 `index.html` PWA.

---

## 업데이트가 폰에 반영되지 않을 때

깃허브 업로드는 정상인데 폰 화면이 예전 그대로라면, **폰에 설치된 예전 서비스워커가
캐시에 저장해 둔 옛 화면을 계속 내주고 있는 것**입니다. 서버 문제가 아닙니다.

가장 쉬운 방법은 앱 안에서 해결하는 것입니다.

1. 앱 아래 **백업** 탭을 엽니다
2. **앱 최신 버전으로 새로고침** 버튼을 누릅니다
3. 확인창에서 계속을 누릅니다 (운동 기록은 그대로 유지됩니다)
4. **앱 정보 → 버전**이 `V8.2` 이면 성공입니다

그래도 안 되면 (아직 옛 버전이라 위 버튼 자체가 없는 경우):

- **아이폰 Safari**: 홈 화면 앱을 길게 눌러 삭제 → Safari 에서 주소를 다시 열고
  공유 → 홈 화면에 추가
- **안드로이드 Chrome**: 설정 → 개인정보 보호 → 인터넷 사용 기록 삭제 →
  캐시된 이미지 및 파일
- 주소 끝에 `?v=2` 를 붙여서 한 번 열어도 됩니다

기록은 서비스워커 캐시가 아니라 별도 저장소(localStorage)에 있으므로
위 작업으로 사라지지 않습니다. 그래도 불안하면 먼저 JSON 백업을 받아두세요.

V8.1 부터는 새 버전이 올라오면 앱이 스스로 감지해서 알려 주므로
이 과정을 다시 할 일은 없습니다.

## 업로드할 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (CSS·JS 포함) |

예전 버전의 잔재이므로 깃허브에서 삭제해도 됩니다.

## V7.1 에서 바뀐 것

### 고친 버그
- **날짜를 UTC 로 계산하던 문제.** 새벽 0~9시 운동이 전날로 기록되던 것을 지역 시간 기준으로 수정.
- **볼륨이 0 으로 남던 문제.** 지난 세션에서 미리 채워진 중량·횟수가 저장되지 않아
  완료 체크만 하면 볼륨과 추이가 0 이었습니다. 이제 체크 시 화면의 값을 기록으로 확정합니다.
- **휴식 타이머가 어긋나던 문제.** 화면을 끄면 실제보다 느리게 가던 것을 시각 기준 계산으로 변경.
- **새 버전이 반영되지 않던 문제.** 서비스워커가 HTML 까지 캐시 우선으로 처리하던 것을
  네트워크 우선으로 변경. 새 버전 감지 알림과 수동 새로고침 버튼 추가.
- 차트 축 라벨이 잘리던 문제 (`120kg` 이 `20kg` 으로 보이던 현상).
- 테마와 맞지 않던 색 잔재 (하단 탭의 주황색, 빨간 그림자).
- 390px 화면에서 헤드라인이 D-day 와 겹쳐 3줄로 깨지던 문제.

### 대체 운동 (V8.2)
- **대체 운동이 기본 운동과 기록 칸을 공유하던 문제를 수정.** 스미스 벤치로 55kg 를 입력하면
  바벨 벤치 기록이 55kg 로 덮어써지고, 메인 리프트 추이가 급락한 것처럼 그려졌습니다.
  이제 기계별로 기록을 따로 보관합니다 (`벤치프레스` / `벤치프레스@스미스 벤치프레스`).
- 대체 운동을 고르면 **그 기계의 지난 기록**을 먼저 불러옵니다.
- 그 기계 기록이 아직 없으면 **기본 운동의 지난 중량**을 시작값으로 넣고
  `시작값 추정` 표시를 붙입니다. 기계마다 체감 중량이 달라 그대로 쓰지 말고 조정하세요.
- 기록이 전혀 없으면 프로그램 기본 중량과 **목표 횟수 범위의 아래값**이 들어갑니다
  (예: `6~8` 이면 6). 기존에는 횟수 칸이 비어 있었습니다.
- 메인 리프트 추이 차트는 **기본 운동 기록만** 그립니다. 대체 기계로 한 세션은 그 선에서 공백이 됩니다.
  중량이 비교 불가능한 값끼리 한 선에 섞이지 않게 하기 위함입니다.
- 대시보드에 **대체 운동 기록** 카드를 추가해 기계별 최고 중량과 횟수를 따로 봅니다.
- 메모와 드롭세트 체크도 기계별로 따로 저장됩니다.

### 기능
- JSON 복원 전에 현재 기록과 파일 내용을 비교해 보여주는 확인창. 덮어쓰기 직전 상태를 자동 보관.
- 전체 삭제는 2단계 확인.
- 세션 종료 시 세트 수와 볼륨 요약.
- 체성분 추이를 체중·골격근·체지방 3개로 분리. 단위가 다른 값을 한 축에 겹쳐 그리지 않습니다.
- 차트를 누르면 해당 날짜 값이 표시됩니다.
- 세트 체크 시 전체 목록을 다시 그리지 않고 해당 줄만 갱신합니다.

### 디자인
- 딥 네이비 + 시안 → 중립 근흑색 + 라임 액센트.
- 상단 히어로(문구 + D-day + 단계)를 유지하되 겹침 없이 재구성.
- 카드에 안쪽 하이라이트와 그림자를 넣어 입체감 부여. 배경에 은은한 광원 두 개.
- 글래스모피즘과 이모지 제거, 선 아이콘(Tabler, MIT)으로 교체.
- 모든 터치 대상 44px 이상.
- 운동 목록이 첫 화면에서 보이도록 순서 재배치. 주간 스케줄과 루틴 체크는 목록 아래로.
- 웹폰트를 9개 파일에서 Pretendard Variable 동적 서브셋 1개로 축소.
- `prefers-reduced-motion` 과 `prefers-reduced-transparency` 지원.
