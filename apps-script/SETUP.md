# 구글 시트 동기화 설정 (처음 한 번, 약 10분)

앱 데이터는 지금처럼 폰에 저장되고, 동시에 **내 구글 계정**의 시트와 드라이브에 자동으로 복사됩니다.
외부 서버를 거치지 않고 내 구글 계정 안에서만 동작합니다.

## 1. 구글 시트 만들기
1. PC에서 [sheets.new](https://sheets.new) 를 열어 새 시트를 만듭니다.
2. 이름을 `BodyProfile 기록` 등으로 바꿉니다.

## 2. 코드 붙여넣기
1. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
2. 기본으로 있는 `Code.gs` 내용을 모두 지우고, 이 폴더의 [Code.gs](./Code.gs) 전체를 붙여넣습니다.
3. 폰 앱의 **백업 탭 → 구글 시트 동기화 → 토큰 생성**을 누르면 토큰이 만들어집니다.
4. 코드 맨 위 `const TOKEN = 'PASTE-YOUR-TOKEN-HERE';`의 따옴표 안을 그 토큰으로 바꿉니다.
   (토큰은 비밀번호 역할입니다. 다른 사람에게 공유하지 마세요.)
5. 저장(💾)합니다.

## 3. 권한 승인
1. 편집기 위쪽 함수 선택에서 `authorize`를 고르고 **실행**을 누릅니다.
2. 구글 로그인 → "확인되지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)으로 이동 → 허용**을 누릅니다.
   내가 만든 스크립트라 구글 검수를 받지 않았을 뿐입니다. 이 스크립트는 이 시트와 드라이브의 `BodyProfile Backups` 폴더만 사용합니다.

## 4. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택(⚙️)에서 **웹 앱**을 고릅니다.
3. **실행 사용자: 나**, **액세스 권한이 있는 사용자: 모든 사용자**로 설정합니다.
   (앱이 로그인 없이 보내기 위해 필요합니다. 토큰이 맞지 않으면 아무것도 읽거나 쓸 수 없습니다.)
4. **배포**를 누르고, 나오는 **웹 앱 URL**(`…/exec`로 끝남)을 복사합니다.

## 5. 앱에 연결
1. 폰 앱 **백업 탭**에 웹 앱 URL을 붙여넣습니다. 토큰 칸에는 3단계에서 만든 토큰이 이미 들어 있습니다.
2. **연결 테스트** → "✅ 연결됨"이 나오면 **지금 동기화**를 누릅니다.
3. 시트에 탭이 자동으로 생깁니다.

| 탭 | 내용 |
|---|---|
| 세트기록 | 모든 세트 한 줄씩 (날짜·종목·중량·반복·완료·볼륨·점검) |
| 세션 | 운동한 날별 완료율·볼륨·시간 |
| 체성분 | 날짜·기기(270S/620)·체중·골격근·체지방·허리 + 체지방량·내장지방·복부지방률·기초대사량·점수·위상각·측정시각·출처 |
| 루틴 | 프리로드·크레아틴·물·일어나기 체크 |
| 종목요약 | 종목별 최근/역대 최고중량, 최근 5회 흐름, 상승·유지·하락·정체 |
| 데이터점검 | 앱이 찾은 이상값 목록 |
| 동기화정보 | 마지막 동기화 시각 등 |

## 이후 동작
- **자동 동기화**: 기록 후 30초 뒤, 세트 전체 완료·운동 종료·체성분 저장 시 바로, 앱을 닫을 때.
- **백업 파일**: 드라이브 `BodyProfile Backups` 폴더에 `latest.json`과 날짜별 사본(최근 60일)이 쌓입니다.
- **폰을 바꾸거나 데이터가 지워졌을 때**: 새 기기에서 URL·토큰을 입력 → **시트에서 복원**.
- **덮어쓰기 방지**: 기기 데이터가 시트보다 30% 넘게 적으면 저장을 막고 복원을 먼저 묻습니다.

## 아내 앱 연결 (V8.4)
같은 시트와 같은 웹앱을 함께 씁니다. 시트를 새로 만들 필요가 없습니다.
1. **Code.gs 교체 후 새 버전 배포**: Apps Script 편집기에서 Code.gs를 최신 파일로 통째로 바꾸고, 맨 위 TOKEN을 기존 토큰으로 다시 넣은 뒤 **배포 관리 → ✏️ → 버전: 새 버전 → 배포**. (URL은 그대로)
2. 아내 폰에서 `https://bluestarlights.github.io/fitness-tracker/wife.html` 열기 → 공유 → **홈 화면에 추가**.
3. 아내 앱 **백업 탭**에 같은 웹앱 URL과 **같은 토큰**을 입력 → 연결 테스트 → 지금 동기화.
4. 시트에 `아내 · 세트기록`, `아내 · 세션` … 탭이 따로 생기고, 드라이브에는 `latest-wife.json`으로 백업됩니다. 남편 탭은 그대로입니다.

## Code.gs를 고친 경우
**배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**로 다시 배포하세요. URL은 바뀌지 않습니다.
(새 배포를 만들면 URL이 바뀌니 앱에 다시 입력해야 합니다.)

## 문제 해결
- **연결 실패**: URL이 `/exec`로 끝나는지, 액세스 권한이 "모든 사용자"인지 확인하세요.
- **토큰이 일치하지 않습니다**: Code.gs의 TOKEN과 앱의 토큰이 같은지, 수정 후 새 버전으로 배포했는지 확인하세요.
